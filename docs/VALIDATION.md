# 검증 요약 — 무엇을 재서 무엇을 버렸나

이 저장소의 강점은 모델 성능이 아닙니다. **바꾼 것이 정말 도움이 되는지 판별하는 절차**입니다.
학습한 모델은 대부분 기존 방법을 넘지 못했고, 그 사실을 구간과 함께 남겼습니다.
이 문서는 그 기록을 한 장으로 모은 것입니다. 각 줄의 근거는 링크한 ADR과 [`EXPERIMENTS.md`](../EXPERIMENTS.md)에 있습니다.

- 평균이 아니라 쌍체 95% 구간으로 판정합니다.

## 2. 모델을 세우기 전에 문제부터 쟀습니다

- **직접 인용 예측을 기각했습니다.** 실제 간선의 95.7%가 공통 이웃 0이라, 그래프 피처에 신호가 없었습니다. 그래서 과제를 공동인용으로 바꿨습니다([ADR-011](adr/ADR-011-cocitation-link-prediction.md)).
- **`published` 필드를 시간 기준으로 쓰지 않았습니다.** 수집분의 27%가 수집 창 날짜를 갖고 있어서, arXiv ID의 연·월을 씁니다.
- **관련 논문 자리에는 모델이 필요 없었습니다.** 정답이 공동인용이라, 그 정의를 세는 Cypher 한 줄이 이깁니다. 이 정답으로는 모델을 잴 수 없다는 점까지 적었습니다([ADR-030](adr/ADR-030-related-papers-needs-a-query-not-a-model.md)).
- **LightRAG·GraphRAG 비교는 하지 않았습니다.** 부분 색인 500편에 정답이 1.2%밖에 없어서, 공정하게 비교할 수 없었습니다.

## 4. 평가 도구 자체를 의심했습니다

- **결함을 일부러 심었습니다.** 결함 4종을 심은 20건에서 지표가 1.000 → 0.000으로 떨어지는지 봤습니다.
  누락은 잡지 못한다는 것, Context Precision은 검색 지표가 아니라는 것도 함께 나왔습니다([11-10](../EXPERIMENTS.md#11-10-지표가-나쁜-답을-걸러내는가--결함을-심어-확인-2026-10-17)).
- **판정 모델이 입력 순서에 흔들리는지 쟀습니다.** 결정 판정은 40건 중 0건이 바뀌었습니다.
- **3회로 정한 하한을 4·5회차로 다시 쟀습니다.** 하한이 버티지 못해서 파국용으로 내렸습니다([11-13](../EXPERIMENTS.md#11-13-4회차가-3회로-정한-하한을-깨뜨렸습니다-2026-10-18)).
- **승격 판정을 일부러 나쁜 모델로 시험했습니다.** 학습 라벨을 섞은 모델(MRR 0.2838)이 거부되고, `--force`로 올린 뒤 `--rollback`으로 되돌렸습니다([ADR-032](adr/ADR-032-close-the-model-lifecycle.md)).

## 5. 제 가설이 틀린 기록

- **`coauthor-03`은 결함이 아니라 변동이었습니다.** 결함이라고 보고 고치려다, 11회 연속 정답이 나와 가설을 버렸습니다([10절](../EXPERIMENTS.md#10-coauthor-03은-변동인가-결함인가)).
- **멈춘 5건은 다섯 개의 문제가 아니라 결함 하나였습니다.** 보조 조회가 근거 별칭을 빼먹으면 답 전체가 거부됐습니다([11-7](../EXPERIMENTS.md#11-7-평가에서-멈춘-5건은-왜-멈췄는가-2026-10-16)).
- **틀리게 적은 것은 고치지 않고 날짜를 달아 덧붙입니다.** 당시 숫자는 당시의 사실입니다.

## 6. 머지와 배포를 막는 장치

| 장치 | 하는 일 |
|---|---|
| 회귀 평가 + 품질 게이트 | 답변 경로를 바꾼 PR마다 실제 모델로 돌립니다. 지표 10개 중 하나라도 하한 아래면 머지되지 않습니다. 프롬프트·판정 모델·사례 집합이 기준선과 다르면 비교하지 않습니다([EVALUATION 4절](EVALUATION.md#4-게이트--머지를-막는-규칙)) |
| Cypher 가드 | 모델이 쓴 Cypher를 읽기 전용 세션 · 계획 유형 검사 · 프로시저 허용 목록의 세 겹으로 막습니다. 40가지로 공격해 쓰기 20/20을 막았고, 외부 읽기 2건을 찾아 막았습니다([ADR-048](adr/ADR-048-the-type-check-does-not-know-the-internet.md)) |
| 모델 승격 판정 | 휴리스틱 대비 구간이 0을 제외하고 MRR 0.60 이상일 때만 `production`이 됩니다. 조건이 없으면 거부합니다 |
| 수집 적재 전 검사 | 임베딩 커버리지 100%, 멱등 적재 확인, 실패율 임계값을 봅니다. 실패하면 알림 이슈를 엽니다([ADR-104](adr/ADR-104-weekly-ingest-runs-on-the-vm.md)·[106](adr/ADR-106-alert-when-the-vm-ingest-stops.md)) |
| 문서 검사 | 문서의 수치를 보고서에 묶고, 링크·명령·ADR 규칙을 CI에서 검사합니다 |

## 한계

- 평가 세트가 작습니다(그래프 조건 30문항, 바꿔 말하기 60문항). 판정은 LLM이 합니다([EVALUATION 5절](EVALUATION.md#5-한계--이-평가가-주장하지-않는-것)).

  승격 기준 아래로 떨어지면 알립니다([ADR-124](adr/ADR-124-rescore-the-forecast-model-every-month.md)). 2026-10은 휴리스틱 대비 +0.0312로 아직 기준 위입니다.
