# ADR-120: 긴 논문 목록은 도구에서 10행으로 자른다 — 지시문은 바꾸지 않는다

- **상태:** 채택
- **날짜:** 2026-11-09

## 맥락

VM에서 화면 예시 7문항을 두 번 쟀습니다(2026-11-09, 3ee8abb·4e51cca). 두 번 모두 10초를 넘긴 문항은
예시 5 "Attention Is All You Need를 인용한 논문을 알려 줘" 하나였습니다(서버 12.9초 / 12.0초).

- 턴은 세 개입니다. `resolve_paper`가 한 턴을 더 쓰지만 1~1.6초입니다.
- 시간은 **마지막 턴**에서 납니다. 8.1초 / 7.6초 동안 961 / 999토큰을 썼습니다.
- 그래프에서 이 논문을 인용한 논문은 403편입니다. 지시문이 "LIMIT 25 이하"이고 논문은 한 편이 한 행인
  표로 쓰라고 하므로, 모델은 25행 표와 근거 ID 25개를 씁니다.

예시 3의 4e51cca 측정(10.4초)은 번역이 3.6초(다른 측정 1.5초)였던 실행 간 흔들림으로 봅니다.

## 결정

- **`search_graph`가 논문 행을 앞 10행만 돌려줍니다**(`src/row_cap.py`).
  - 논문 행은 `evidence_ids`가 비지 않은 행입니다.
  - 순서는 Cypher의 ORDER BY 그대로입니다.
- **뺀 행 수를 `rows_omitted`로 함께 돌려줍니다.** 모델이 "더 있다"고 말할 수 있게 합니다. 행이 10개
  이하면 이 필드는 없고 결과는 예전과 같습니다.
- **집계 행(`evidence_ids`가 `[]`)은 자르지 않습니다.** 짧고, 빼면 합계가 틀립니다.
- **지시문, 도구 설명, 인자는 그대로입니다.** 모델이 받는 스키마가 바뀌지 않습니다.

## 측정

로컬에서 한 프로세스로 상한을 끈 것(main과 같음)과 켠 것을 번갈아 세 쌍씩 돌렸습니다. Aura를 쓰고,
순서는 라운드마다 바꿨습니다.

| 문항 | | main | 10행 |
|---|---|---|---|
| 예시 5(인용 403편) | `generate` | 14.04 / 14.75 / 13.15초 | 10.29 / 8.77 / 9.49초 |
| | 마지막 턴 | 9.53초·1,050토큰 / 10.04초·1,031 / 8.82초·922 | 5.45초·471 / 4.58초·429 / 5.02초·469 |
| | 근거 ID | 25 | 10 |
| 예시 2(피인용 상위 5편, 대조) | `generate` | 4.78 / 5.52 / 5.51초 | 5.50 / 5.96 / 5.41초 |

- 예시 5는 `generate`가 약 4.5초 줄었습니다. 출력이 절반 아래로 줄었습니다.
- 행이 10개 이하인 대조 문항은 같은 범위 안입니다. 출력 토큰도 같습니다.
- 첫 라운드 main의 전체 30.9초는 프로세스의 첫 질문이라 붙은 준비 시간입니다. `generate`는 다른 라운드와 같습니다.

10행 답은 "그래프에 적어도 25편이 있고 그중 10편을 보인다"고 적었습니다. 근거 ID는 표의 10편과 같았습니다.

## 고르지 않은 것

- **표를 앱이 도구 결과로 그리기**(관련 논문 표처럼). 가장 많이 줄지만, "목록을 쓰지 말라"는 지시문이
  필요합니다. 지시문은 모든 질문의 턴이 읽습니다(ADR-090). 판정 입력도 바뀌어 유료 평가가 필요합니다.
- **지시문의 "LIMIT 25"를 "LIMIT 10"으로.** 같은 효과를 지시문 변경으로 얻습니다. 위와 같은 이유로 고르지 않았습니다.
- **그대로 두기.** 인용이 많은 논문은 대표적인 질문이고, 화면 예시이기도 합니다.

## 민감도

- **"20편 알려 줘"도 10편이 됩니다.** 모델은 `rows_omitted`를 보고 더 있다고 적습니다. 더 보려면 탐색 화면을 씁니다.
- **"적어도 25편"은 실제 수(403편)가 아닙니다.** Cypher가 LIMIT 25로 끝나므로 도구는 전체 수를 모릅니다.
  전체 수가 궁금한 질문은 모델이 집계로 따로 셉니다.
- **평가.** 저장된 케이스의 정답 ID는 그래프 목록 문항에서 10편 이하입니다. 검색 지표는 k=5입니다.
  회귀 평가(smoke)는 PR에서 돕니다.
- **`src/`가 바뀌어 머지하면 VM API가 다시 뜹니다**([ADR-107](ADR-107-restart-the-api-only-when-it-reads-the-change.md)).
