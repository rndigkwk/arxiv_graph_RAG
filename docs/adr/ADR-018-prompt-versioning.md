# ADR-018: 프롬프트 본문은 한 모듈에 모으고 버전은 MLflow에 남긴다

- **상태:** 채택
- **날짜:** 2026-10-16

## 맥락

프롬프트를 손으로 고치다 **두 번 회귀를 냈습니다.**

- 심판 지시문에 `requires_graph` 오탐을 잡으려고 한 문장을 넣었다가 `requires_content` 정확도가
  **21/21에서 11/21로** 떨어졌습니다. 두 판정이 한 호출에 묶여 있어 설명이 번집니다.
- 집계 순위를 고치려고 Cypher 규칙에 넣은 문장이 `topcited-04`·`topcited-06`을 깨뜨렸습니다.

둘 다 **고친 뒤에 재서** 알았습니다. 더 나쁜 것은, 어느 문장이 어느 점수였는지가 **제 기억에만**
있었다는 점입니다. 본문은 함수 안쪽 리터럴로 흩어져 있어 이름도 없었습니다.

## 결정

**텍스트의 단일 출처는 [`prompts.py`](../../src/prompts.py)이고, 버전 이력은 MLflow 프롬프트
레지스트리에 둡니다.** 앱은 레지스트리를 조회하지 않습니다.

| 프롬프트 | 하는 일 |
|---|---|
| `CYPHER_RULES` | `search_graph`의 조회용 Cypher 규칙 |
| `AGENT_SYSTEM` | 에이전트 지시문 |
| `JUDGE_CONTENT` | 최종 후보를 내용·그래프 조건과 대조 |
| `TRANSLATE_TO_ENGLISH` | 비영어 질의를 DB 언어로 ([ADR-010](ADR-010-korean-translate-only-when-needed.md)) |
| `TRANSLATE_TO_KOREAN` | 영어 답변을 한국어로 |

## 왜 앱이 레지스트리를 조회하지 않는가

질문마다 조회하게 만들면 **배포 앱이 MLflow와 네트워크에 매입니다.** 추적 서버가 죽으면 챗봇이
죽고, 측정한 메모리 259MB도 그 가정 위에 있습니다([ADR-016](ADR-016-stay-on-streamlit.md)).
레지스트리가 맡는 것은 실행이 아니라 **이력**입니다.

연결은 **지문**으로 합니다. `sha256` 앞 12자를 평가 보고서의 `metadata.prompt_versions`에 적어
두면 "이 점수는 어느 프롬프트였나"가 기억이 아니라 조회가 됩니다. `git_sha`만으로는 부족합니다
— 프롬프트를 안 고친 커밋에서도 점수는 흔들립니다([ADR-017](ADR-017-regression-gate.md)의
변동 측정).

## 대가

프롬프트가 코드에서 한 칸 멀어집니다. 고칠 때 파일을 하나 더 열어야 합니다.

`prompts.py`는 `E501`을 면제했습니다. **프롬프트 본문은 코드가 아니라 데이터**이고, 줄 길이를
맞추려고 줄바꿈을 넣으면 모델이 읽는 글이 바뀌어 지문과 측정값이 어긋납니다.

## 옮기면서 찾은 것

옮긴 뒤 "긴 문자열 리터럴이 남아 있는가"를 테스트로 확인했더니 **번역 도구의 지시문 두 개가
남아 있었습니다.** ADR-010이 쟀던 번역 경로만 이름도 버전도 없이 돌고 있었습니다. 옮긴 본문이
원문과 바이트 단위로 같은지는 `git show HEAD:chatbot.py`의 AST와 대조해 확인했습니다.

## 민감도

**DagsHub가 프롬프트 레지스트리를 지원하는지가 전제였습니다.** 2026-10-16에 다섯 개를 version 1,
별칭 `production`으로 올려 확인했습니다. 지원하지 않으면 등록 단계가 오류를 보고서에 적고
지문은 그대로 남습니다 — 지문이 없으면 이력도 없지만, 지문만으로도 되짚기는 됩니다.

**본문이 다시 코드로 흩어지면 이 결정이 무효가 됩니다.** [`tests/test_prompts.py`](../../tests/test_prompts.py)가
그것을 막습니다 — 등록 목록 누락, 긴 리터럴 재등장, 자리표시자 소실, 회귀를 냈던 두 문장의
존재를 각각 확인합니다.

## 재현

```bash
uv run python -m pipeline.prompt_registry --manifest            # 지문만 (네트워크 없음)
uv run python -m pipeline.prompt_registry --register --alias production
```
