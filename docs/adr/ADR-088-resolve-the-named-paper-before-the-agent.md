# ADR-088: 질문이 지칭한 논문은 에이전트 전에 앱이 찾는다 — 제목 해석에 모델 턴을 쓰지 않는다

- **상태:** 채택
- **날짜:** 2026-10-27

## 맥락

번역을 에이전트 밖으로 뺀 뒤([ADR-087](ADR-087-translate-before-the-agent.md)) VM 답변 p50은 10.40초, p90은 16.93초였습니다.
p90을 만든 두 문항(`reference-01` 17.3초, `coauthor-03` 16.9초)은 모두 **제목으로 한 논문을 지칭하는 질문**입니다.
도구는 둘 다 0.5초 아래였고, 시간은 3~4턴의 모델 시간이었습니다.

이 질문들은 모델이 먼저 `resolve_paper`를 부르고, 결과를 읽은 **다음 턴에** Cypher를 씁니다. 순서가 필요해 한 턴에
묶을 수 없습니다. 15문항 중 9문항(citing·reference·coauthor)이 이 모양이고, 턴 하나는 VM에서 약 2.5초입니다.

## 결정

**그래프의 `resolve` 노드가 질문 전체로 `resolve_paper`를 부르고, 확실할 때만 그 arxiv_id를 이번 턴의 메시지로
붙입니다**([`src/pre_resolve.py`](../../src/pre_resolve.py)). `translate` 다음, `route` 전입니다.

- **질문에서 제목을 잘라내지 않습니다.** 잘라내는 규칙은 평가 문장의 틀("the paper titled X")에만 맞고, 실제 질문에서는
  돌지 않으면서 평가에서만 빨라집니다. `resolve_paper`의 판정은 제목 쪽 적중률(`title_coverage`)을 보므로 질문의 덧붙은
  낱말에 무너지지 않습니다.
- **확실할 때만 씁니다.** `arxiv_id`가 있고 `ambiguous`가 아니면 힌트를 붙입니다. 못 찾음·약한 일치·애매함은 아무것도
  하지 않고, 모델이 지금처럼 `resolve_paper`를 부릅니다. 도구는 모델에게 남습니다.
- **결과는 도구 호출 기록 모양으로 붙입니다**(`by: "app"`). 근거 허용 목록(`resolved`)과 관련 논문 시드
  ([ADR-086](ADR-086-the-app-ranks-related-papers-not-the-model.md))가 모델이 찾았을 때와 같은 기록을 읽습니다. 앞당긴 관련 논문
  호출에도 같은 기록을 넘겨, 최종 시드와 어긋나지 않게 합니다.
- 지시문에 한 줄을 더합니다: 앱이 이미 찾았으면 그 arxiv_id를 쓰고 `resolve_paper`를 다시 부르지 말 것.

## 먼저 잰 것 — 질문 전체로 찾으면 맞는가

VM에서 OpenAI 없이 `resolve_paper`에 질문 전체를 넣었습니다(2026-10-27, 읽기만).

| 질문 | 결과 |
|---|---:|
| 평가 문장 그대로(citing·reference·coauthor 18문항) | 18/18 맞음 |
| 같은 제목, 다른 틀의 영어 문장("papers that cite X") | 18/18 |
| 같은 제목, 한국어 문장("X 논문을 인용한 논문 알려줘") | 18/18 |
| 같은 제목, 전부 소문자 | 17/18, 1개는 `ambiguous`(힌트 없음) |
| `cases.json`의 제목 질문 21개("Find the paper titled: X") | 21/21 특정 |
| 제목이 없는 질문(저자·집계 12, 주제 검색 10) | **잘못 특정 0** |

## 얼마나 줄어드는가

제목 질문 9/15에서 턴 하나, 약 2.5초입니다. `resolve` 노드 자체는 0.1~0.4초입니다(VM `resolve_paper` p50 0.12초).
제목이 없는 질문에는 그 0.1~0.4초가 더해집니다.

## 민감도

- **제목이 없는 질문에 논문이 걸릴 수 있습니다.** 주제가 짧은 제목과 같으면("hyperbolic neural networks에 관한 논문")
  그 논문을 특정합니다. 힌트는 "질문이 이 논문에 관한 것이 아니면 무시하라"고 하지만, 관련 논문 시드가 그 논문이 됩니다.
  주제 검색 10문항에서는 0건이었습니다.
- **후속 질문**("그 논문의 참고문헌은?")은 제목이 없어 찾지 못하고, 지금처럼 모델이 앞 턴에서 찾습니다.
- **지시문이 바뀌었습니다**(`AGENT_SYSTEM` 지문). 머지 전에 full 평가 3회로 품질을 확인하고 기준선을 다시 씁니다
  ([ADR-041](ADR-041-the-gate-reads-the-prompt.md)). 근거 지표가 기준선 아래면 뒤집습니다.
