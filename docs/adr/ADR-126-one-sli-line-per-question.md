# ADR-126: 질문마다 SLI 한 줄을 남기고, 그 줄로 좋은 요청 비율을 센다 — 지표 서버는 두지 않는다

- **상태:** 채택
- **날짜:** 2026-11-11

## 맥락

답변 지연 목표는 p50 10초입니다([ADR-084](ADR-084-answer-p50-under-10s-measure-the-vm-first.md)).
그런데 그 값은 **측정 스크립트를 돌릴 때만** 보였습니다(`scripts/measure_vm_answer_latency.py`, 우리가 고른 15문항).
`/api/ask`는 실패할 때만 로그를 남겼으므로, 실제 사용자 질문이 얼마나 걸렸는지, 몇 개가 기권했는지는 알 길이 없었습니다.

교안(Day 79)은 Prometheus `/metrics`로 이것을 셉니다. 여기서는 맞지 않습니다.
워커가 하나라 수가 메모리에 있으면 재시작마다 0이 되고, 긁어 갈 서버를 VM(4GB)에 더 올려야 합니다.
하루 질문도 수십 건 이하입니다.

## 결정

- **질문마다 JSON 한 줄을 표준 오류에 씁니다**(`src/sli.py`, 접두어 `ask_sli `). 컨테이너 로그가 모읍니다.
  - 남기는 것: 결과(`final`·`abstain`·`error`), 전체 시간, 첫 조각 시간, 모델 턴, 시도 횟수, 입력·캐시 읽기·출력 토큰, 그 답을 만든 코드의 커밋(`LOADED_COMMIT`), 오류면 예외 이름.
  - **질문과 답은 남기지 않습니다.** 시험이 질문 글자가 줄에 없는지 확인합니다.
  - 끝 이벤트를 보내기 **전에** 씁니다. 기록이 실패해도 답은 막지 않습니다(`ask_sli_failed`만 남깁니다).
- **턴마다 입력 토큰과 캐시 읽기를 같이 적습니다**(`src/tool_timing.py`의 `turns`). 프롬프트 캐시가 깨졌는지를 운영 트래픽에서도 보려는 것입니다.
- **집계는 스크립트가 합니다**(`scripts/summarize_sli.py`, 표준 라이브러리만). VM 호스트에서:

  ```bash
  docker logs --since 24h arxiv-graphrag-vm-api-1 2>&1 | python3 scripts/summarize_sli.py
  ```

  - **좋은 요청 = 답이 10초 안에 끝난 것**입니다. 기권과 오류는 분모에만 들어갑니다. 교안의 "좋은 요청 비율"과 같은 정의입니다.
  - p50·p90은 답이 나온 질문만, 위치로 읽고 보간하지 않습니다(측정 스크립트와 같은 방식).
  - `--commit`으로 한 배포가 답한 질문만 볼 수 있습니다.

## 고르지 않은 것

- **Prometheus `/metrics`와 히스토그램.** 위의 이유입니다. 요청마다 한 줄이면 원하는 구간의 줄만 고르면 되므로, 두 스냅샷의 차이로 구간 비율을 계산할 필요도 없습니다.
- **`/api/health`에 최근 N건의 요약을 보이기.** 배포 점검이 읽으면 알림까지 이어지지만, 하루 수십 건에서 비율로 알리면 한두 건에 흔들립니다. 몇 주 줄이 쌓인 뒤에 기준을 정할 수 있으면 다시 봅니다.
- **에러 버짓과 소진 속도.** 같은 이유로 트래픽이 모자랍니다.
- **Langfuse 운영 trace.** VM은 `LANGFUSE_TRACING=0`입니다([ADR-023](ADR-023-what-to-trace.md)). 이 줄은 외부로 나가지 않습니다.

## 민감도

- **컨테이너를 다시 만들면 그 전 로그가 사라집니다.** 이미지를 다시 굽는 배포(의존성 변경)와 VM 재부팅 뒤의 `up`이 그렇습니다. 재시작만 하는 배포([ADR-107](ADR-107-restart-the-api-only-when-it-reads-the-change.md))는 남습니다. 오래 모아야 하면 그때 파일로 옮깁니다.
- **로그는 돌려 쓰지 않습니다**(Docker `json-file` 기본값). 한 줄이 300바이트 안팎이라 하루 수십 건이면 1년에 수 MB입니다.
- 토큰은 에이전트 턴만 셉니다. 조건 판정 호출(`validation_usage`)은 `generate` 밖이라 들어가지 않습니다.
