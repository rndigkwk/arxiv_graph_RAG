# ADR-011: 링크 예측 과제를 직접 인용에서 공동인용으로 바꾼다

- **상태:** 채택
- **날짜:** 2026-10-15

## 맥락

개선안 A는 "인용 그래프로 모델을 학습한다"였습니다. 자연스러운 과제는 "논문 A가 B를 인용할까"
이고, 69,438개 `REFERENCES` 관계가 그대로 라벨이므로 라벨링 비용이 0입니다.

## 결정

직접 인용 예측을 **기각**하고 "두 논문이 앞으로 같은 논문에 함께 인용될까"(공동인용)로 바꿉니다.

## 근거

**모델을 만들기 전에 그래프 구조를 먼저 쟀습니다.**

| 측정 | 직접 인용 | 공동인용 |
|---|---:|---:|
| 쌍·간선 | 69,438 | **929,725** |
| **공통 이웃 > 0 비율** | **4.3%** | — |
| 평균 공통 이웃 / 차수 | 0.066 | **59.4** |
| 양쪽에 인·아웃 간선이 모두 있는 논문 | **269** / 37,854 | — |

원인은 수집 방식입니다. "최근 논문을 모으고 그 논문의 참고문헌을 보강"이었으므로 간선이
최근 → 과거 한 방향으로만 뻗고 과거 논문의 참고문헌은 수집하지 않았습니다. 그래서 그래프가
별 모양에 가깝고 **삼각형이 거의 없습니다.**

공통 이웃이 0인 간선이 **95.7%** 면 그래프 피처에 신호가 없고, "그래프 피처 → 그래프+텍스트 →
GNN" 사다리가 전부 같은 점수로 끝납니다. 직접 인용 예측은 사실상 텍스트 유사도 모델이며,
그것을 "인용 그래프로 학습했다"고 말할 수 없습니다.

## 대가

과제가 덜 직관적입니다("A가 B를 인용할까"보다 설명이 한 줄 더 듭니다).

평가 라벨의 **74%가 cold-start**(한쪽이 피처 그래프에 없음)라 과제를 "이미 그래프에 있는 논문
사이"로 한정했고, 그 74%는 별도 문제로 떼어 측정했습니다.

## 민감도

**과거 논문의 참고문헌을 수집하면 결론이 바뀝니다.** 삼각형이 생기면 직접 인용에도 그래프
신호가 생깁니다. 다만 그것은 Aura 관계 한도(84.6%)를 바로 치므로 현재 제약에서는 불가능합니다
([ADR-001](ADR-001-neo4j-graph-and-vector.md)).
