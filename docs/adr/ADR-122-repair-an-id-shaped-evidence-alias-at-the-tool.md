# ADR-122: arXiv ID 모양인 근거 별칭은 도구에서 고쳐 받는다 — 별칭이 없는 행은 그대로 돌려보낸다

- **상태:** 채택 ([ADR-019](ADR-019-validate-evidence-alias-at-the-tool.md)가 기각한 대안 두 개를 뒤집음)
- **날짜:** 2026-11-10

## 맥락

ADR-019는 `search_graph`의 행이 `evidence_ids`를 arXiv ID 문자열 리스트로 갖지 않으면, rows 대신 error를
돌려줍니다. 모델은 그 메시지를 읽고 조회를 다시 씁니다. 답이 거부되지는 않지만 **모델 턴 하나가 더** 듭니다.

11-09에 공저자 질문의 턴이 3~4개였던 것을 보다가, 그래프 평가 문항을 로컬에서 물어 봤습니다.

| 모양 | 예 | 관측 |
|---|---|---|
| 문자열 하나 | `p.arxiv_id AS evidence_ids` → `"2303.14382"` | coauthor-01, coauthor-04, topcited-03 |
| 단수 별칭 | `[p.arxiv_id] AS evidence_id` | author-01 |

두 모양 모두 ADR-019가 관측한 것과 같습니다. ADR-019는 이것들을 고쳐 받는 대안을 기각했습니다.

- 단수 별칭: "모델의 의도를 추측하는 것"이라는 이유였습니다.
- 문자열 하나: "한 편인지 여러 편인지 알 수 없다"는 이유였습니다.

## 결정

- **`search_graph`가 행을 검사하기 전에 `evidence_alias.repair`를 거칩니다.**
- **`evidence_ids`가 문자열이고 그 문자열이 arXiv ID 하나와 통째로 맞으면 `[ID]`로 감쌉니다.**
  - 새 형식(1706.03762, v 붙은 것 포함)과 옛 형식(adap-org/9708006, math.AG/0101001)을 받습니다. 그래프에는 옛 형식이 160편 있습니다.
  - 쉼표로 이은 문자열, 제목, 숫자는 그대로 둡니다. 뒤의 검사가 지금처럼 error로 돌려보냅니다.
- **`evidence_ids`가 없고 `evidence_id`가 ID 하나 또는 ID 리스트이면 `evidence_ids`로 옮깁니다.**
- **별칭이 아예 없는 행은 고치지 않습니다.** `arxiv_id` 칸이 있어도 그렇습니다. 논문 행인지 집계 행인지 알 수 없습니다.
- `check_evidence_alias`와 `validate_answer`는 그대로입니다. 답의 인용은 여전히 그 조회가 돌려준 ID와 대조합니다.

ADR-019의 걱정에 대한 답입니다.

- **"한 편인지 여러 편인지"**: ID 하나와 통째로 맞는 문자열은 한 편입니다. 아닌 것은 고치지 않습니다.
- **"의도를 추측한다"**: 값은 그래프가 돌려준 ID 그대로입니다. 이름만 바꿉니다. 지어낸 인용은 여전히 `validate_answer`가 막습니다.

## 측정

로컬(Aura)에서 그래프 평가 문항 30개를 한 프로세스로 물었습니다. 고쳐 받기를 끈 것(main과 같음)과 켠 것을 번갈아 묻고,
순서는 문항마다 바꿨습니다.

| | main | 고쳐 받기 |
|---|---|---|
| 별칭 오류가 난 문항 | 2 | 0 |
| 모델 턴이 3개 이상인 문항 | 3 | 0 |
| `search_graph`를 두 번 이상 부른 문항 | 3 | 0 |
| `generate` p50 / 평균 | 4.58 / 4.92초 | 4.43 / 4.55초 |

- 다시 쓴 조회 하나가 2~4초를 더했습니다(coauthor-04 8.6초, topcited-03 6.6초).
- 턴이 3개였던 나머지 한 문항(coauthor-02)은 별칭 오류가 아닌 다른 이유로 조회를 다시 썼습니다.
- 그 전에 따로 물은 15문항에서도 2문항이 같은 길로 갔습니다.

## 고르지 않은 것

- **지시문에 별칭 규칙을 한 번 더 강조하기.** 지시문은 모든 질문의 턴이 읽습니다(ADR-090). 규칙은 이미 있고, 모델은 대부분 지킵니다.
- **`arxiv_id` 칸을 근거로 삼기.** 별칭이 없는 행입니다. 집계 행에도 ID 칸이 있을 수 있어 의도를 모릅니다.

## 민감도

- **잘못된 ID 문자열도 ID 모양이면 받습니다.** 그래도 그 값은 그래프가 돌려준 값입니다. 답이 그것을 인용하면 판정이 그 논문의 조건을 봅니다.
- **회귀 평가(smoke)는 PR에서 돕니다.** 평가 문항에서 별칭 오류는 드물어서(7%), 효과는 위 짝 측정으로 봅니다.
- **`src/`가 바뀌어 머지하면 VM API가 다시 뜹니다**([ADR-107](ADR-107-restart-the-api-only-when-it-reads-the-change.md)).
