# 지식 그래프·GraphRAG 실습자료

엔코아 AI캠퍼스 「데이터 분석 & AI 머신러닝 캠프」 **지식 그래프 및 GraphRAG 시스템 설계** 실습용 주피터 노트북입니다.
수업 진도에 맞춰 자료가 추가됩니다.

### 수록 자료

| 일차 | 주제 | 배우는 것 |
|---|---|---|
| **day27** | 그래프DB 개념·지식그래프 | 관계형 데이터베이스 vs 그래프DB(2단계 `merge` vs 인접 dict 순회), **LPG 모델**(노드·레이블·속성·방향 관계)을 파이썬으로 모델링, 1홉/2홉 순회, `networkx` 시각화. 그리고 **지식 그래프**. 공개 지식 그래프 **Wikidata** 에 SPARQL 로 직접 질의해 사실을 받아 오고(파일 없음), **온톨로지**로 담을 범위를 정해 걸러 내고, **RDF 트리플**(주어-술어-목적어)·URI·리터럴·`rdf:type` 을 익힌 뒤, **rdflib** 으로 내 그래프에 **진짜 SPARQL** 을 실행합니다(`SELECT`·`ASK`·`CONSTRUCT`·`INSERT`/`DELETE`, `FILTER`·`UNION`·`OPTIONAL`·`NOT EXISTS`·`BIND`, `COUNT`/`GROUP BY`, 속성 경로 `/`·`*`). 마지막으로 공개 엔드포인트에 질의를 보내 `wd:`·`wdt:` 를 읽고 요청 제한(429)에 대처합니다 |
| **day28** | Neo4j 설치·노드/관계/속성 | **Neo4j Desktop**(로컬, 권장)과 **Aura**(클라우드) 중 하나를 골라 설치하고 인스턴스를 켠 뒤, 접속 정보를 `.env` 로만 설정해 **파이썬 드라이버**로 첫 연결을 합니다(같은 코드로 원격 Aura 에도 붙어 봅니다). **Query** 편집기에서 그래프를 눈으로 확인하고 **Movies 예제 그래프**(노드 171·관계 253)를 적재해 첫 조회를 돌립니다. 이어서 **LPG 모델**을 Neo4j 위에서 다룹니다: 노드와 **레이블**, **관계와 방향**, 같은 두 노드를 잇는 **여러 관계**, 노드·관계 양쪽의 **속성**, 그리고 표(RDB)와의 대응·모델링 원칙. 설치 절차는 `day28_Neo4j_설치_Movies/환경_구축_가이드.md` 를 그대로 따르면 됩니다 |

## 시작하기

### 1. 환경 만들기: uv

이 저장소는 [uv](https://docs.astral.sh/uv/) 로 파이썬 환경을 관리합니다. `pyproject.toml`·`uv.lock` 이
들어 있으므로 **명령 한 줄이면 수업과 똑같은 환경**이 만들어집니다.

```bash
# uv 가 없다면 먼저 설치 (macOS·Linux)
curl -LsSf https://astral.sh/uv/install.sh | sh

# 저장소를 받은 폴더에서
uv sync            # .venv 생성 + 잠긴 버전 그대로 설치
```

VS Code 로 노트북을 열고 커널은 **Python 3 (ipykernel)** (= 방금 만든 `.venv`)를 고릅니다.

### 2. API 키는 필요 없습니다

day27 의 교안_02 는 공개 지식 그래프 **Wikidata** 에 직접 질의해 데이터를 받아 옵니다. 가입도 키도 필요 없습니다.

> 공개 엔드포인트는 요청이 몰리면 `429`(요청 제한)로 거절합니다. 교안이 그 뜻과 대처를 함께 다룹니다.

### 3. Neo4j 는 day28 부터

다음 일차부터 그래프 전용 데이터베이스 **Neo4j** 를 씁니다. day27 의 마지막 절에 내려받는 방법이
안내돼 있으니 **수업 전에 미리 받아 두세요**.

## 실습 진행 순서

각 일차 폴더의 **`실습_가이드.md`** 를 위에서부터 따라가면 빠짐없이 완주할 수 있습니다.

1. **교안**(`교안_01` 부터 번호 순서대로)을 실행하며 읽습니다.
2. `🖐️ 함께 따라하기` 는 직접 타이핑하고, 붙어 있는 **확인 기준**과 내 출력을 대조합니다.
3. **과제**를 `LV1` → `LV2` 순서로 풉니다. 답안 셀을 채우고 **자가채점 셀**이 `✅ 통과!` 를 찍으면 맞은 것입니다.
4. 막히면 각 문제의 **힌트**를 펼쳐 봅니다.
